테이블 SDK의 종료 후 불필요 보유 경로 **3개를 확정하고 수정했다.** 그러나 최종 전체 성능은 **83 PASS / 26 FAIL**이다. 세 경로의 수정과 26개 수치 FAIL의 전체 원인 규명을 동일한 결론으로 처리하지 않는다. **0.2.4 출시·전체 Goal은 미완료**다.

- GC root 판정은 각 snapshot 내부 강한 경로와 실제 제공 SDK source SHA를 사용했다. 시점 간 object ID를 제품 동일성으로 사용하지 않았다.

- 기존 popup-only 컬럼 그룹, 기존 Pending 수치, RAF 완료 뒤 이동하는 virtual300 수치 FAIL의 원인으로 위 재현을 소급 귀속하지 않는다.
