# 2026-09-16 CRUD column4 편집 수정

- 작성 시각: 2026-09-16T17:28:29+09:00
- 요청: 기본 > CRUD에서 column4 수정이 반영되지 않는 문제 수정.
- 결과: 표시 데이터 `column1`~`column6`와 내부 Row 식별자를 분리하여 6개 필드 모두 수정 가능하도록 변경했습니다.

## 원인과 변경

- 기존 `getRowId`가 `column4`를 사용했고, 수정 시 `{ ...row, ...parsed, column4: activeRowId }`로 입력값을 원래 값으로 덮어썼습니다.
- 별도 `id`를 생성·유지하고 수정·선택·삭제를 해당 값 기준으로 처리합니다. `column4` 값이 변경되거나 다른 Row와 같아져도 Row 식별자는 유지됩니다.
- JSON 편집창에는 화면과 같은 `column1`~`column6`만 표시합니다. 내부 `id`를 수동 입력해도 원래 식별자를 유지합니다.
- 이전 E2E는 column4 변경 요청을 넣고도 column1·column2만 검증했습니다. 실제 column4 값, 나머지 필드, 재선택 JSON, 재수정과 중복 값 이후 선택·삭제를 검증하도록 보강했습니다.
- Playground 코드 예제, 영문·국문 CRUD/Playground 문서 및 0.1.11 변경 이력을 갱신했습니다.
