- 각 경로의 대표 조작만 수행했습니다. 모든 카드/옵션, 장시간 메모리/성능, 화면 크기 전체, OS별 Clipboard, Firefox/WebKit/Safari는 미검증입니다.

### API 계약과 변경 파일

- `cell.validateFill`은 동기 선택 옵션입니다. `false` 반환 또는 예외는 **Fill 전체를 취소**하고 React에서는 `onClipboardError`를 호출하며 Ref는 `false`를 반환합니다. Core helper는 예외를 전달합니다.
- 검증에는 원래 destination Row와 typed candidate를 전달합니다. 변경 없는 Cell 및 보호된 대상은 검증하지 않습니다. Viewport callback에는 절대 인덱스를 전달합니다.
- 기본 Fill은 기존 typed 반복 동작을 유지하며 `parseClipboard`를 재사용하지 않습니다. 검증 callback에서 Row를 직접 수정하거나 비동기 검증을 수행하는 계약은 제공하지 않습니다.
- 구현: `src/index.tsx`, `src/core.ts`, `src/column-filter.tsx`.
