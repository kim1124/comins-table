## 요약

- Playground Sidebar의 그룹명과 route 링크명을 locale과 무관하게 영어로 통일했다. Article, 검색 metadata, code sample, control과 접근성 label의 한/영 전환은 유지한다.
- Tree Grid의 첫 선언 컬럼을 Tree 기준 컬럼으로 고정했다. 해당 Header는 이동 Handle을 표시하지 않으며 다른 컬럼도 기준 위치를 가로지를 수 없다.

- 10만 Row 최하단 성능 검증은 마지막 논리 Row가 실제 mount된 뒤 Border를 측정하도록 안정화했다.

## Ready for review 후속 코드 리뷰

- 독립 병합 전 리뷰에서 `onLazyLoad` callback identity 변경 시 initial 요청이 반복되는 문제, saved layout이 locked Group 위치를 우회하는 문제, `getRowId` 변경 시 자동 Detail 측정값이 다른 owner에 재사용되는 문제를 확인했다.
- 비메모화 inline `onLazyLoad`가 state update로 다시 render되어도 initial 요청은 한 번만 유지하고, 요청 시점에는 최신 committed callback을 ref로 사용하도록 보정했다.
- locked Group이 초기 saved layout과 `setColumnLayout` 복원 모두에서 선언 위치 범위를 유지하도록 Group-aware order 정규화를 추가했다.
- `getRowId` identity 변경 시 자동 Detail 측정 cache를 비우고, Row ID 배열 변경을 기준으로 제거된 ID의 측정값을 정리하도록 변경했다.
- 최종 diff 점검에서 동일 ID를 반환하는 inline `getRowId` 재생성까지 전체 cache를 비우는 회귀를 재현했다. 함수 identity가 바뀌더라도 같은 ID가 다른 Row 객체에 재매핑된 항목만 제거하고 동일 매핑은 측정값을 유지하도록 정밀화했다.
- 첫 Group 보정의 독립 재검토에서 역순 선언된 복수 locked Group과 Group 내부 locked Leaf가 순차 이동으로 다시 밀리거나 분리되는 경계를 추가 확인했다.
- locked Header를 경계로 movable Entity 구간을 유지하고 Group을 하나의 Entity로 정규화한 뒤, Group 내부 locked Leaf의 group-aware 선언 위치를 복원하도록 재설계했다.
