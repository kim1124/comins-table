## 요약

- Playground Sidebar의 그룹명과 route 링크명을 locale과 무관하게 영어로 통일했다. Article, 검색 metadata, code sample, control과 접근성 label의 한/영 전환은 유지한다.
- Tree Grid의 첫 선언 컬럼을 Tree 기준 컬럼으로 고정했다. 해당 Header는 이동 Handle을 표시하지 않으며 다른 컬럼도 기준 위치를 가로지를 수 없다.
- Tree Expander를 현재 visible index가 아니라 Tree 기준 컬럼 ID에 결합하여 컬럼 layout 변경 뒤 다른 데이터 Cell에 붙는 결함을 제거했다.
- 초기 layout과 `setColumnLayout`도 `lockPosition` 컬럼의 선언 위치를 보존하도록 column order 정규화를 보강했다.
- Virtual content가 viewport보다 짧을 때 마지막 Row의 하단 Cell Border를 유지한다. Content가 viewport를 채운 상태의 최하단에서는 외곽 Table Border만 사용한다.
- 10만 Row 최하단 성능 검증은 마지막 논리 Row가 실제 mount된 뒤 Border를 측정하도록 안정화했다.
