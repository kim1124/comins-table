## 작업 요약

- README 첫 설명을 controlled ownership 중심으로 정리하고 전체 기능 카탈로그를 추가했다.
- 패키지 설치 코드 바로 아래에 저장소 clone, `npm ci`, `npm run dev`, 로컬 URL을 포함한 Playground 실행 절차를 추가했다.
- README에는 Table, Pinning, Grouping, Filtering, Tree, Transfer를 전환하는 Hero GIF 1개를 배치했다.
- Column Pinning, Row Grouping, Column Filtering, Cross-Table Drag의 상세 GIF 4개는 영문·한글 기능 가이드로 이동했다.
- `docs/README.md`, `docs/user/README.md`, `docs/ko/README.md`를 추가하고 23개 영문·한글 가이드에 상위 인덱스, 상대 언어, Playground 탐색을 연결했다.
- 25개 공개 Playground 경로와 `/api/props`가 하나 이상의 상세 가이드에 연결되도록 문서 계약을 추가했다.
- 다중 GIF 교체는 전체 교체 완료 전 실패만 rollback하고, 교체 완료 후 backup 정리 실패는 완성된 새 자산 집합을 유지하도록 원자성 경계를 명확히 했다.
- 캡처 상호작용의 고정 대기를 bounded state polling으로 교체하고, `docs/README.md`를 문서 변경 검증 범위에 포함했다.
- 생성 자산의 Spoqa Han Sans Neo OFL-1.1 증빙과 fail-closed license fixture를 다섯 파일에 맞췄다.
