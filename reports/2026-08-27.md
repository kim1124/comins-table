## 요약

- criterion 기반 다중 Depth Row Grouping을 application-owned 단일 Depth `groups` 모델로 교체했다.
- `groups` 배열 순서를 실제 Group 순서로 사용하고 빈 Group을 유지하며 Group CRUD는 application이 소유하도록 했다.
- Group Drag, 같은/다른 Group Row Drag, pure Group/Row move helper, 전체 Group 펼침/접힘 Ref API를 추가했다.
- Group Row를 visible Column 전체를 span하는 하나의 `<th scope="rowgroup">`로 렌더링하고 custom content renderer와 별도 배경색을 적용했다.
- Header 정렬은 Group 순서를 변경하지 않고 동일한 sort model을 각 Group 내부 Row에 독립 적용한다.
- 접힌 Group으로 Row 이동 시 stable Group ID를 기준으로 target disclosure에 focus를 복구한다.

## 추가 반영 - Group Row 시각 구분 및 커스텀 스타일

- Group Row 기본 배경을 일반 Row와 구분되는 중립 회색으로 교정하고, dark theme 값을 포함한 `--comins-table-group-row-background`, `--comins-table-group-row-color` 토큰을 추가했다.
- `rowGrouping.getGroupRowProps`를 추가하여 typed Group params로 각 Group Row의 `className`과 `style`을 지정할 수 있게 했다. Fixed-height virtualization 계약상 callback의 `height`는 `rowHeight`를 덮어쓰지 않는다.
- Playground에서 Group별 custom content와 CSS 변수/class 스타일을 함께 시연하고, 공통 300px 높이 규칙이 Row Grouping 예제를 덮어쓰지 않도록 수정했다.
- README, CHANGELOG, 영문/한글 Row Grouping 및 Styling 문서, Playground route/option/sample 설명을 동기화했다.
