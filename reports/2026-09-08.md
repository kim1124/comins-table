## 실패와 해결

- 환경: 초기 로컬 서버 bind와 Git 설정/브랜치 쓰기는 sandbox 권한 제한이었다. 승인된 로컬 범위로 실행했다. npm pack은 기본 로그/cache 경로 쓰기 제한으로 실패하여 임시 cache를 지정했고 동일 산출물 검사를 통과했다.
- 테스트 구성: headed 옵션을 describe 내부에 두어 발생한 Playwright 오류는 별도 headed spec으로 분리했다. native scrollbar의 0px gutter는 scrollbar-color와 pseudo scrollbar 설정의 충돌을 확인해 테스트 CSS에서 해소했다. thumb 입력 검증에 programmatic/wheel fallback은 넣지 않았다.
- 제품: 고정 높이 Tree 이동 후 focus는 매 commit의 stable ID로 복구하도록 수정했다. 희소 응답 배열의 빈 항목은 오류로 처리했다. Viewport Clipboard guard의 압축 인덱스 사용은 절대 인덱스 projection으로 수정했다. 각각 실패 조건과 관련 회귀를 확인했다.
- 문서 계약: 새 기능 ID/메뉴/브라우저 spec 매핑과 한영 문구, npm README 링크, 이전 미지원 문구 검사 누락을 수정했다. 최종 전체 게이트에서 재검증했다.

## 잔여 범위 및 인계

- 커밋, push, PR, merge, tag, Release 및 npm publish는 수행하지 않았다. 원격 main과 공개 npm 버전 변경을 주장하지 않는다.
- 자동 검증은 Chromium 범위다. Firefox/Safari, 실제 서버 네트워크·인증·저장 연동, 임의의 모든 Renderer/CSS 조합은 실행 검증하지 않았다.
- Viewport는 전체 count와 안정적인 ID/index 순서가 필요하다. 정렬·필터 조건 변경 시 queryKey를 교체하며, 서버 저장과 캐시 밖 미저장 편집 보존은 애플리케이션 책임이다.
- Viewport의 Tree/Grouping/Detail/행 이동/append/pagination 및 server push는 합의한 제외 범위다. 자동 높이의 미측정 구간과 퇴출한 높이 이력은 추정값을 사용한다.
