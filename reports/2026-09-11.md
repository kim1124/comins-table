## 변경 내용

1. CRUD Row 데이터를 `column1`~`column6`으로 정리하고 표시 헤더와 일치시켰다. `column4`는 안정적인 Row ID이며 JSON 수정 시 유지한다. 다른 예제의 Column label은 실제 field명과 대소문자까지 일치시켰고, Export 헤더와 표시 코드도 맞췄다. 스타일·Renderer 설명과 Header Group 제목은 설명 용도를 유지한다.
2. 비가상화 Body의 위치 기준을 설정해 스크롤 후 재조회 overlay가 Body 안에 유지되도록 했다. 수평·수직 스크롤 시 overlay 위치를 동기화하며, 로딩하지 않을 때는 추가 DOM 검색을 하지 않는다.
3. Lazy Load는 1,000개 예제 Row를 100개씩 비동기 로딩한다. 외부 데이터 제공자의 전체 건수에 의존하지 않으며 요청 지연·취소·초기화·종료를 유지한다. 네트워크 응답을 사용하는 Loading 및 Infinite Scroll 예제는 별도로 유지한다.
4. Header Group 1의 초기 자식 너비를 160/160px로 맞췄다. Group 2도 140/140px로 맞췄다.
5. Pinning의 grouped 예제에서 controlled Group/Row 이동을 활성화했다. Row Grouping에 이동 허용 체크박스를 제공해 이동 제한을 확인할 수 있도록 했다.
6. `rowSelectionOnClick={false}`로 Cell 조작과 Row 선택을 분리할 수 있다. 기존 기본값은 `true`다. `getSelectedRows()`, `getSelectedCells()`, `getSelection()`, `copySelection(target?)` Ref API를 추가했다. OS 키보드 복사는 `clipboard`로 활성화하며 기본값은 기존 내부 버퍼 동작을 유지하는 `false`다. 복사 우선순위는 여러 Cell → 선택 Row → 단일 Cell이다. 우클릭 메뉴에서 `auto`/`cells`/`rows`를 선택할 수 있으며 선택 내부의 우클릭은 기존 범위를 보존한다.
7. Summary 라벨을 실제 집계 값 직전까지 colSpan으로 병합했다. 스타일 예제의 마지막 집계도 남은 빈 Column까지 병합하고, Pinning Summary는 pin 경계를 보존한다.
8. Tree Row 이동 예제의 부모 변경 허용과 자동 높이를 기본 활성화했다.

## 선택/복사 계약

- Row 5개와 Cell 3개 선택 시 Cell 3개를 복사하며 Row 5개는 조회할 수 있다. Row 5개와 Cell 1개 선택 시 Row를 복사한다.
- `getSelectedCells()`는 `{ rowId, columnId, value }`의 원본 값을 반환한다. 선택 snapshot의 배열·주소는 복사본이며 Row 객체와 Cell 값은 application 소유 참조다.
- 조회는 로딩된 데이터만 반환하고 Viewport 요청을 추가로 실행하지 않는다. Cell 사각형이 미로딩 구간을 가로지르면 복사를 거절한다.
- Copy는 visible Column과 projected Row 순서를 사용한다. 비연속 Cell의 미선택 위치 및 copy guard로 제외한 위치는 비워 두며 내부 paste는 해당 위치를 건너뛴다.
- TSV의 탭·줄바꿈·인용부호와 문자열 수식 접두어를 처리한다. 원본 값은 내부 paste 버퍼에 유지한다.
- `copySelection()`의 브라우저 접근 실패는 Promise rejection으로 전달한다. 키보드 복사는 native copy 이벤트를 사용한다. 체크박스 포커스에서도 Row를 복사하고 일반 텍스트 입력은 native copy를 유지한다.
- 외부 OS clipboard 데이터의 import/paste는 추가하지 않았다. 기존 내부 버퍼 paste를 유지한다.
