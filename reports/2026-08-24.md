## 요약

- PR #43의 `@vitejs/plugin-react 6.1.0`, Vite `8.2.2`, Vitest `4.1.11` 변경을 현재 `main` 기준으로 통합했다.
- Vite가 추가로 사용하는 Lightning CSS `1.33.0`을 MPL-2.0 개발 전용 도구로 재검토했다. 기존 Tailwind 경로의 `1.32.0` 승인과 새 `1.33.0` 승인을 모두 보존하며, source, bundle, source map, npm artifact에 포함되지 않는 조건을 유지한다.
- jsdom `30.0.1`은 Node `^24.15.0` 이상을 요구하지만 현재 로컬 Node 24 기준선은 `24.14.0`이어서 `EBADENGINE`을 재현했다. PR #42 변경은 통합하지 않고 jsdom `29.1.1`을 유지했다.
- Loading / Empty E2E의 `80ms`, `120ms`, `220ms`, `260ms` 고정 지연을 제거하고 각 remote response를 테스트가 명시적으로 해제하는 deferred gate로 교체했다.
- 비교 기준 없이 PNG만 생성하던 Visual Typography artifact 과정을 제거하고 폰트와 root overflow assertion만 유지했다.
- 180회 route 이동을 반복하던 `lifecycle-soak.spec.ts`를 삭제했다. 기본 Localization lifecycle 테스트와 `memory-leak-full-audit @perf`가 active mount, unmount, browser diagnostics, memory lifecycle 계약을 중복 없이 검증한다.
- CI는 retry 후 성공도 flaky 실패로 처리한다. 로컬 Playwright는 기존 서버 재사용을 명시적으로 요청한 경우에만 허용하고, 격리 worktree는 `PLAYWRIGHT_PORT`로 별도 포트를 사용할 수 있다.
- README 테스트에서 Playwright 설정 파일의 정확한 문자열을 비교하던 change-detector assertion을 제거했다.

## 실패 분류와 RED

- 의존성 업데이트 직후 license gate는 Lightning CSS `1.33.0` 및 11개 platform package의 정확 버전 승인이 없어 26/27로 실패했다. 라이선스 게이트는 정상 동작이므로 제거하지 않았다.
- Lightning CSS `1.33.0` 승인으로 기존 `1.32.0` 승인을 교체했을 때 Tailwind 경로의 1.32.0이 차단됐다. 두 버전이 lockfile에 공존함을 확인하고 버전별 승인을 분리했다.
- 기본 Playwright 포트 4002는 주 worktree에서 실행 중인 사용자 서버가 점유하고 있었다. 해당 프로세스를 종료하거나 재사용하지 않고 격리 포트 4003을 사용했다.
- sandbox 내부 포트 bind는 `listen EPERM`으로 실패해 실행 환경 실패로 분류했고, 동일 코드의 승인된 외부 실행에서 검증했다.
