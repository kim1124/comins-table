## 요약

- Header 좌측에 24px 이동 Handle과 15px Radix icon을 기본 표시하고, `showColumnMoveHandle={false}` 및 Column/Group `lockPosition` 계약을 추가했다.
- 위치 lock은 source 이동과 다른 source가 locked 위치를 가로질러 index를 변경하는 이동을 모두 차단한다.
- 유효 Drop은 파란색 테두리·저투명도 배경, 무효 Drop은 붉은색 테두리·저투명도 배경으로 구분하며 content opacity는 유지한다.
- Header move commit 뒤 Header/body/Summary Cell에 FLIP 방식 수평 이동 animation을 적용하고 reduced-motion에서는 비활성화했다.
- built-in Header control을 유지하기 위한 기본 최소 Column 너비를 88px로 조정했다.
- Row Expand 카드의 Table을 sample 내부 높이에 고정하고 body viewport가 Detail 세로 scroll을 소유하도록 수정했다.
- Playground의 non-expandable owner 카드를 제거하고 공개 `isRowExpandable` API 및 문서는 유지했다.
- Row/Tree disclosure는 하나의 `ChevronRightIcon`을 CSS로 160ms 회전하며 reduced-motion을 지원한다.
- 정렬 완료 상태는 기존 15px box 안에서 Radix `ThickArrowUpIcon`/`ThickArrowDownIcon`을 사용하고, exact icon inventory와 MIT notice를 함께 갱신했다.
- 측정형 자동 Detail은 body Cell의 실제 높이를 Row token에 맞추고 mixed virtual range의 물리 scroll 입력을 sizer 범위로 clamp하여, Detail 증가 뒤 반복 scroll에서도 `scrollHeight`와 scrollbar thumb가 안정적으로 유지된다.
- Row Expand Playground의 fixed/automatic/tall 예제는 callback의 마지막 ID만 보존하여 한 번에 하나만 확장한다. 라이브러리의 복수 ID controlled API는 유지한다.
- 활용도가 낮은 read-only controlled 카드도 Playground에서 제거했으며, callback 생략 시 disabled read-only가 되는 공개 계약과 문서는 유지했다.
- Lazy Load의 내부 Row/total 저장을 제거했다. `onLazyLoad`는 `void | Promise<void>` request callback이고 application이 `data`, `loading`, `loadingMore`, `hasMoreRows`를 소유한다.
- DummyJSON Playground의 Refresh는 Row 배열과 total을 먼저 초기화하고 offset 0, reason `refresh`로 fetch 결과를 다시 매핑한다.
- Selection & Clipboard Playground의 상태 출력 높이를 고정하여 Cell drag 중 Table이 아래로 이동하던 레이아웃 변화를 제거했다.
- 기존 미커밋 Row Expand/Row Drag/value 한 줄 배치 변경을 보존했다.

## 2026-08-14 Loading / Empty 원격 API 예제

### 변경

- Loading / Empty 예제와 Infinite Scroll 예제가 공유하는 example 전용 DummyJSON `/users` URL builder, response type, `PersonRow` mapper를 추가했다.
- 최초 진입과 `초기 로딩`은 controlled Row를 비운 뒤 실제 fetch 동안 5개 skeleton Row를 표시하고, 응답 30개를 매핑한다.
- `재조회 로딩`은 기존 30개 Row를 유지한 채 실제 fetch를 수행하여 overlay를 표시한다.
- `빈 데이터`는 로컬 배열을 직접 비우지 않고 offset `10000`의 실제 빈 원격 응답을 매핑한다. `데이터 표시`는 offset `0`을 다시 요청한다.
- 하단 Lazy Load 연동의 timer/local fixture를 같은 원격 API fetch로 교체했다. Data는 callback offset, Empty는 offset `10000`을 사용한다.
- 새 요청은 기존 주 예제 요청을 abort하고 request version으로 오래된 응답을 차단한다. Lazy Load 연동은 Table의 `signal`과 intent version을 함께 확인한다.
- English/Korean Loading 문서, Playground 상태 정책, route 설명, code sample과 feature metadata를 원격 controlled data 계약에 맞췄다.
