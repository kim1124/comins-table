## 검증 및 발견 사항

- 새 Clipboard GIF는 실제 복사·붙여넣기와 Fill Handle 포인터 드래그를 수행하며 두 번째 숫자 값, 세 번째 Cell 보존, 최종 반복 값과 변경 횟수를 확인.
- Tree 촬영에서 마지막 자식 Row가 5px 잘리는 것을 기존 브라우저 검사로 재현. README 전용 세로 여백을 줄여 전체 subtree와 캡션 표시를 복원.
- Viewport 촬영의 native thumb 드래그는 별도 직접 조작에서는 약 66만 번째 구간으로 이동했지만 연속 프레임 촬영에서는 불안정. 촬영 스크립트는 실제 휠 입력으로 약 60만 번째 구간에 이동하고 조회 결과를 검증하도록 변경. 라이브러리 스크롤 로직 변경 없음.
- 필터 팝오버와 거부 Tooltip이 GIF 오른쪽 경계에서 잘리지 않도록 브라우저와 이미지 너비를 960px로 일치시킴.
- 신규 GIF가 CI metadata 대상에서 빠지는 회귀 검사를 확인하고 분류 목록을 보완.
- 전체 `npm run verify` 통과: 38개 파일, 468개 테스트, 문서 계약, 위생, 결정적 보안/라이선스, TypeScript 및 build 포함.
- 관련 README 브라우저 테스트 8개 통과. 촬영 입력 영역의 마지막 정돈은 GIF 생성 시나리오로 추가 검증.
- 전체 UI/성능 테스트는 문서 및 README 전용 데모 변경에서 재실행하지 않음. 기존 최종 휴먼 리뷰와 별도 증거임.
- 최종 GIF metadata 및 사용자 문서 검사 52개 통과. macOS ImageIO 디코더와 별도 프레임 디코딩으로 9개 GIF / 총 471프레임 검증. 모든 파일은 960×655, 무한 반복, 3.1–11.1초이며 최대 494,861 bytes.
- 각 GIF의 첫·중간·마지막 프레임을 시각 점검했고, 마지막 촬영 너비 보정 후 필터 팝오버와 중복 ID Tooltip이 모두 이미지 안에 표시되는지 재확인. 최종 해시와 metadata는 `gif-metadata.json`에 기록.
- 마지막 GIF 교체 후 위생·라이선스 검사 및 diff whitespace 검사 통과.
