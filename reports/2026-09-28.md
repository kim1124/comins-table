- `src/model.ts`: 프레임워크 독립 Row ID, Row 이벤트 데이터, 선택, 정렬,
  레이아웃, 클립보드·Export 데이터 계약을 분리했다.
- `src/react-types.ts`: 기존 React Renderer·이벤트·컴포넌트·테이블 계약을
  원래 구조 그대로 이동했다. `src/core.ts`의 기존 이름을 그대로 재노출한다.
- `src/row-height.ts`, `src/tree.ts`, `src/viewport-data.ts`, `src/virtual-layout.ts`:
  공통 타입을 직접 참조하여 React facade 및 `index.tsx` 역참조를 제거했다.
- `src/column-layout.ts`: 너비 제한·분배·그룹 내부 리사이즈와 불변 너비 갱신.
- `src/table-state.ts`: 정렬 순환, 컬럼 순서 복원, 선택 유지 판단.
- `src/row-value.ts`: 기존 중첩 Input 값의 불변 갱신.
- `src/index.tsx`, `src/core.ts`: 추출된 계산을 사용하도록 연결했다.
- `test/core-isolation.test.ts`: React 및 React 타입 패키지가 없는 임시 소비자
  환경에서 공유 모델과 계산 모듈을 실제 TypeScript 컴파일한다.
- `test/table-calculations.test.ts`: 제한 너비 재분배, 숨김 컬럼, 정렬 우선순위,
  선택 ID 및 불변 중첩 갱신을 검증한다.

## 후속 범위와 제한

- 공개 `comins-table/core`는 React 타입 호환 facade다. 전체 공개 Core가
  React 타입 독립성을 달성했다고 주장하지 않는다.
- Grouping·Summary·Filter의 Renderer 관련 타입, DOM transfer 등록,
  전체 상태 동기화, 스크롤 보정 적용, 요청 스케줄러 분리는 후속 범위다.
- React Hook과 DOM·Pointer 처리는 유지한다. 기존 알고리즘의 기능 개선이나
  지원 조합 확장은 수행하지 않았다.
- 원격 push, PR, commit, merge 및 release는 수행하지 않았다.
