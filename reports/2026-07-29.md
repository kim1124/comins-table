## Release 및 Migration Notes

- Controlled Infinite Scroll, Selection & Clipboard, Ref API를 실제 React 소비자 흐름으로 확인할 수 있는 Playground와 영문/한글 문서를 제공한다.
- Infinite Scroll refresh 시 request offset과 virtual viewport를 처음부터 다시 시작한다.
- cell range, row drag, header resize의 active pointer listener를 완료, 취소, 교체, unmount 시 제거하고 pointer release 뒤 compatibility event가 선택 범위를 덮어쓰지 않도록 수정했다.
- Lucide runtime 및 bundled source를 제거하고 정렬/accessibility 계약은 module-owned CSS와 텍스트 glyph로 유지한다.
- 기존 import, exports, types, CSS entry, data/callback 소유권은 변경하지 않아 소비자 migration은 필요하지 않다.
