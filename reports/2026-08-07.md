## 2026-08-07 최종 후속 수정 1–4

### 요약

- Automatic Detail의 accepted measurement는 owner Slot을 `rowId -> slotIndex`로 찾아 `CominsHeightIndex.updateHeight()`에 반영한다. 따라서 Detail 한 건의 height-index 갱신은 O(log N)이며, observer batch마다 전체 projection/Fenwick index를 재생성하지 않는다. 같은 commit 전에는 최초 pending anchor를 유지하여 누적 scroll 보정을 한 번으로 coalesce한다.
- README와 Playground의 Row Expand 안내는 finite positive height만 fixed inline height이고, missing·invalid·`"auto"`는 measured automatic Detail이라는 계약으로 정정했다. 문서 테스트는 source text가 아니라 exported `dataTableOptionGuide`를 직접 import하여 Props group 및 height option의 중복·설명 교환을 검증한다.
- Playground localization은 21/21 Feature, 85/85 Feature option, 46/46 Option Guide description, 4/4 Option Guide group title을 explicit Korean/English pair로 고정했다. canonical `FeatureId`, AST/runtime completeness, duplicate/generic/allowlist gate, deterministic Tree Grid 및 docs copy, 실제 `/api/props` route가 같은 locale contract를 사용한다.
- Column Move는 rich ReactNode Header label에서 side-effect-free plain string/id fallback을 만들고, active source `<th>`의 `aria-label`/`aria-labelledby`를 정규화한다. source/group content에는 `inert`, `aria-hidden`, React/native event barrier를 적용하며, 실제 React rich-label fixture에서 content-target pointer lifecycle, valid drop, cancel 및 종료 뒤 복원을 검증한다. visually-hidden placeholder copy는 accessible name의 근거로 사용하지 않는다.
- Detail observer는 `{ projection, contentWidth, viewportHeight }`를 하나의 committed snapshot으로 publish한다. concurrent Suspense로 abort된 render가 기존 observer input을 오염시키지 않으며, StrictMode 회귀 테스트가 stale/current-width measurement와 이후 실제 commit을 함께 검증한다. 후속 capped-height 회귀는 50,000 Rows, logical `1,800,300px`, physical cap `1,500,000px`에서 projection/contentWidth를 고정하고 suspended candidate viewport만 변경해 committed physical `scrollTop` `749,950`을 유지하는지 확인한다.
