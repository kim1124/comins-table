## 요약

- Core와 Playground의 상호작용 아이콘을 exact runtime dependency인 `@radix-ui/react-icons` version `1.3.2`로 표준화했다.
- Core에는 의미 기반 private icon wrapper를 두고 Row Detail, Tree Grid disclosure, Header sort, Column Move ghost에 적용했다. 공개 export와 타입에는 Radix 또는 private icon primitive가 노출되지 않는다.
- Playground는 검색과 Pagination first/previous/next/last 아이콘을 Radix의 직접 import로 사용한다.
- 모든 SVG를 장식 요소로 처리하고 기존 button label, `aria-expanded`, `aria-sort`, click 및 keyboard 계약을 유지했다.
- Radix MIT 원문, exact version, upstream revision, source, 사용 export inventory, downstream notice 의무를 `THIRD_PARTY_NOTICES.md`와 fail-closed gate로 고정했다.
- npm tarball이 Radix 코드를 내부 bundle하지 않고 외부 dependency로 유지하며 public declaration에 icon 구현이 새지 않는지 검증했다.

## 잔여 이슈 및 리스크

- 저장소와 npm tarball은 Radix MIT notice 및 외부 dependency 경계를 fail-closed로 검증한다. 최종 소비자가 자체 application bundle을 재배포할 때 Radix MIT notice를 보존하는지는 Comins가 자동 보증할 수 없다.
- Radix version, revision, integrity, license, import inventory 또는 bundle 방식이 변경되면 현재 검토는 무효이며 provenance와 artifact evidence를 다시 확인해야 한다.
- public icon override API는 추가하지 않았다. 소비자별 icon 교체 요구가 생기면 의미 기반 공개 API를 별도 설계해야 한다.
- dependency 설치 시 npm이 기존 tree에서 moderate 1건과 high 1건의 vulnerability를 보고했다. 이번 라이선스 작업에서 `npm audit fix`는 수행하지 않았으며 별도 보안 범위에서 원인 package와 runtime 영향 확인이 필요하다.
