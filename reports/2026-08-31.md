## 요약

- 보호된 source merge, 병합 후 CI, trusted staging, maintainer 2FA 승인, 공개 registry와 exact public artifact를 독립적으로 확인했다.

- 공개 artifact는 workflow가 검증한 staged tarball과 byte 단위로 동일하며 registry signature, SLSA provenance와 React 18 consumer 동작을 모두 확인했다.

## Source 및 Workflow 근거

- PR #60의 head `5c06dfde32bc00e4a06a1b57baf3103ad7953865`는 merge commit `8e2cdd15cd3a345e56641765eb795a5d0764cb2d`로 `main`에 병합됐다.
- 같은 merge SHA의 post-merge Verify run `33339045836`과 CodeQL run `33339045871`은 모두 성공했다.
- trusted Stage npm package run `33339895361`은 같은 merge SHA에서 `verify-and-pack`과 `stage` job을 모두 통과했다.
- `verify-and-pack`은 Node 24.19.0에서 `verify:local`, Chromium E2E 162개, exact package allow-list, Gitleaks artifact scan과 exact artifact consumer smoke를 통과하고 단일 tarball을 업로드했다.
- stage job은 GitHub `npm` environment 승인 뒤 current npm maintainer gate를 값 비노출 방식으로 통과하고 OIDC trusted publisher로 exact artifact에 `npm stage publish`를 수행했다.
