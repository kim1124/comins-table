# 2026-11-13 헤더 등록 저장소 수정

## 요약

컬럼 그룹과 일반 헤더가 공유하는 네이티브 input/change 등록 여부를 모듈 전역 WeakSet에서 해당 DOM의 비공개 Symbol 원시값으로 옮겼다. 반복 Unmount 후 대상 DOM이 해제되어도 남던 WeakSet backing 용량 이력을 제거한다. 이벤트 본문·capture·공개 API·SSR HTML은 유지한다.

이 수정은 불필요한 SDK 등록 저장소 문제에 한정된다. 강한 DOM 누수나 기존 전체 화면 JS Heap 15% 증가의 원인 전체가 해결됐다는 결론은 아니다. 기존 수치 FAIL과 출시 보류를 유지한다.
